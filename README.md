# Skill Match JS

## O que é este projeto?

O **Skill Match JS** é uma simulação simples que conecta candidatos a vagas de tecnologia com base em suas habilidades.

A ideia é pegar um perfil de candidato e comparar com diferentes vagas disponíveis, gerando uma análise automática de aderência entre eles.

No final, o sistema mostra um panorama geral da compatibilidade e ajuda a identificar pontos de melhoria.

---

## O que este projeto faz?

Durante a execução, o sistema:

- Analisa compatibilidade entre habilidades e requisitos  
- Calcula porcentagem de match para cada vaga  
- Identifica a vaga mais compatível  
- Mostra habilidades que faltam no candidato  
- Gera uma lista de tópicos para estudo  

---

## Por que esse projeto existe?

Este projeto foi criado com foco em prática os principais conceitos do **Módulo 01 de JavaScript**:

- Estruturas de decisão e repetição  
- Manipulação de arrays e objetos  
- Funções e reutilização de código  
- Programação orientada a objetos  
- Herança e polimorfismo  
- Callbacks e closures  
- Assincronismo com Promises e async/await  
- Organização de lógica em um fluxo de trabalho (Kanban)
